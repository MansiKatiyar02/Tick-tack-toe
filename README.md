🎮 Tic-Tac-Toe Game in Python
Welcome to Tic-Tac-Toe, a simple two-player game built entirely in Python without using any external libraries!
This project demonstrates basic programming concepts like functions, loops, and conditionals in a fun way.

✨ Features
Two-player mode (X and O).

Simple command-line interface.

No external libraries required — just pure Python!

Win detection across rows, columns, and diagonals.

🛠️ How It Works
The board is represented using two separate arrays: one for player X and one for player O.

Players take turns entering a number (0–8) corresponding to the board position.
The game checks for a win after every move.
The match ends when either player wins.

🚀 How to Run
Make sure you have Python installed (Python 3 recommended).

Copy the source code into a .py file (e.g., tic_tac_toe.py).

Open a terminal and run:
